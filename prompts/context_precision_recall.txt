PRECISION: split context into distinct chunks/passages. Score = relevant chunks /

Judge precision against the question, not exact overlap with a minimal reference.
All evidenced failure paths/branches in the requested run family are relevant to
a request for that family's failure path, including multiple failed branches.
Supporting run IDs, activity names, timestamps and errors are relevant evidence,
not irrelevant merely because the reference is brief. Unrelated pipeline families,

RECALL: split the reference into required factual claims. Score = claims supported
by retrieved context / all required claims. Do not use the agent answer as evidence.

by the retrieved evidence. Count only claims required by that branch, not mutually
exclusive alternatives. A verified no-runs result covering the correct entity and
time window can provide complete coverage of an allowed absence branch. A lookup
error or missing evidence must not be treated as a verified empty result.
For each, 1.0 means complete relevance/coverage, 0.5 means half, 0.0 means none.
Empty retrieval scores 0.0 unless the reference explicitly establishes that the
requested information does not exist; in that case correct empty retrieval scores
1.0 for both. Without a reference, context recall is null (not applicable).
